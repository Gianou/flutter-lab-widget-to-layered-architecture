# Introduction

## Context and Goals

This lab serves as an introduction to Flutter development. 
It starts with the very basics of Flutter and ends with an intermediate level implementation of **Layered Architecture** using the **Model View View-Model (MVVM)** design pattern.  

It is based on Flutter's official documentation and training materials, and combines elements from:
- [Create an app project](https://docs.flutter.dev/learn/pathway/tutorial/create-an-app)
- [Set up state management project](https://docs.flutter.dev/learn/pathway/tutorial/set-up-state-project)
- [Architecting Flutter apps](https://docs.flutter.dev/app-architecture).

Participants will build a cross-platform frontend application that retrieves and displays a list of movies from an open-source API.
